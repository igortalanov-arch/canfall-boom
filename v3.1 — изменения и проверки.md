# Банкопад: Бум! — v3.1

## Файлы

- **Банкопад — Бум! v3.1.html** — автономная игра, 1 768 489 байт.
- **Банкопад — Бум! v3.1 — VK Mini Games.zip** — Node.js-комплект для выкладки, 1 482 271 байт, 21 файл.

**README в архиве нет**, как вы просили. Версия v3.0 сохранена отдельно.

## Настройки

Удалены:

1. Выбор русского/английского языка.
2. Выбор светлой/тёмной темы.
3. Кнопка «Вернуть 3D».
4. Кнопки сохранения/загрузки прогресса и скрытый файловый ввод.

Удалены и связанные обработчики, чтобы отсутствие элементов не вызывало ошибок. Язык и тема переключаются в верхнем меню; их сохранение после перезагрузки проверено. Выбор качества графики (включая 2D и 3D), звук, громкость, траектория, замедление, размер текста и вибрация сохранены.

В подписи автора отображается v3.1. В других местах интерфейса номер версии не добавлялся.

## Комплект VK

В архиве:

- `DEPLOY.bat` — production-выкладка.
- `DEPLOY-DEV.bat` — dev-выкладка без изменения production URL.
- `START.bat` — локальная сборка и просмотр.
- `package.json`, `package-lock.json`, `VERSION`, `vk-hosting-config.json`.
- `public/` — уже собранные файлы для хостинга.
- `src/` — исходный HTML этой же v3.1 и адаптер VK.
- `tools/` — Node.js-скрипты настройки, сборки, проверки, локального сервера и публикации.

ID приложения **не выдуман и не взят из другой игры**: в конфигурации стоит `null`. При первой интерактивной выкладке скрипт запросит числовой ID «Банкопада». Перед обращением к VK он показывает адрес приложения и окружение и требует подтверждение `YES`.

Публикация использует официальный `@vkontakte/vk-miniapps-deploy` 1.0.3. Конфигурация содержит три точки входа — mobile, mvk и web — с общим `index.html`; структура сверена с документацией утилиты. [1](https://github.com/VKCOM/vk-miniapps-deploy)

VK Bridge 3.0.2 включён локально в сборку, без CDN. `VKWebAppInit` вызывается до игрового модуля, в соответствии с инструкцией VK. [1](https://dev.vk.ru/en/bridge/getting-started)

Обрабатываются события скрытия/возврата: физика и звук приостанавливаются, после возврата продолжение требует нажатия игрока. Учитываются безопасные отступы, переданные клиентом VK. Автоматический выбор темы VK не перезаписывает выбор пользователя.

Не добавлены запросы профиля, реклама, платежи или облачная синхронизация. Прогресс по-прежнему сохраняется локально. Токены и пользовательские учётные данные в архив не включены.

## Запуск без README

Установите Node.js 22 или 24 LTS и распакуйте архив.

- Windows: `DEPLOY-DEV.bat` для тестовой выкладки или `DEPLOY.bat` для основной.
- Через терминал в папке комплекта:

```sh
npm ci
npm run deploy:dev
```

Для production: `npm run deploy`.

Локальная проверка: `npm run build`, затем `npm start` — адрес `http://localhost:8080`.

## Проверки

- В самостоятельном HTML и VK-сборке отсутствуют все шесть удалённых DOM-элементов и их обработчики.
- Язык/тема в верхней панели работают из настроек и сохраняются после перезагрузки.
- Новая подпись автора содержит v3.1; в справке остаются шесть пунктов.
- Самостоятельный HTML запускается через `file://`; при недоступном Worker работает резервный движок, бросок выполняется.
- VK-сборка проверена через Node.js-сервер. В тестовом эмуляторе AndroidBridge инициализация вызвана один раз, во время загрузки документа и до появления игры.
- Через настоящий VK Bridge с эмулированными событиями проверены Init, Hide, Restore и безопасные отступы. Во время скрытия игровое время останавливается; после возврата нужна кнопка продолжения.
- Размеры 390×844, 320×740 и 568×320: переполнения по ширине нет, отступы учтены. Работают Worker и WebGL.
- Регрессия уровня 4: две банки собраны двумя бросками; одиночная корзина, замки уровней и выбранные имена игроков сохранены.
- Код Worker отличается от v3.0 только номером версии; методы основного физического движка и Runner совпадают.
- Архив распакован в папку с кириллицей и пробелами. Чистые `npm ci`, `npm run build`, `npm run check` выполнены успешно; результаты сборки побайтово совпадают с вложенным `public/`.
- Локально проверено создание payload ZIP библиотекой официальной утилиты. Целостность обоих ZIP проверена. README и node_modules в выдаваемый архив не входят.
- Без ID команда проверки выкладки завершается до обращения к VK. Dev-флаги запрещают обновление production URL.

## Ограничения

**Реальная публикация, авторизация и модерация VK не выполнялись:** для этого нужны ID приложения и подтверждение владельца. Нативные события проверялись эмулятором, а не в установленном клиенте VK. BAT-файлы подготовлены для Windows; сами Node.js-команды проверены в Linux.

`npm audit --omit=dev` не обнаружил уязвимостей в клиентских зависимостях. Полный `npm audit` сообщает о 7 умеренных предупреждениях в цепочке архиватора официальной утилиты выкладки (minimatch/glob/archiver). Эта цепочка не загружается в браузер игры. Несовместимое принудительное обновление зависимостей не применялось.

Подробные результаты и скриншоты находятся в `work31/`.
